# Asset name

- Contract version: 1
- Asset ID / role: existing world ID; canonical-room or named-character
- Approval scope: draft / approved direction / exact approved files; link attestation
- Authority: world facts, layout, simulation bindings, composition and identity references
- Retained source / master / display / provenance: repository-relative paths and hashes

## World facts

List established facts with source references. Distinguish story authority from visual interpretation.

## Must preserve

Specify identity, architecture, materials, scale and existing approved visual choices.

## Must not invent

List forbidden entities, routes, accessories, identity changes and misleading story signals.

## Camera / composition

Record view, framing, source crop, negative space, scale, contacts, depth and occluders. Character contracts specify full-body/portrait scope and identity references.

## Art direction

Describe medium, texture, silhouette hierarchy and room-aware light in plain language.

## Dynamic content that must not be baked in

Name simulation-owned actors, props, time-dependent effects and reflections. For isolated sprites, exclude backgrounds and other entities; define the source entity that owns each effect.

## Palette / pixel target

State source/master/display dimensions, alpha, palette treatment and resampling. Record intentional role differences.

## Review criteria

Specify source/master/runtime comparisons, identity checks, actual state cases, mobile/Off/Reduced, technical hash validation and the human approval scope. Record accepted polish separately from blockers.

## Maintenance / history

Explain how to edit retained PNGs and reimport without any model. Link provenance, prior decisions, workflow JSON and manual history. Every changed image is a new draft until approved.
