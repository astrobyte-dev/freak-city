# First night: THE CARBON COPY

1. Establish immutable canon, three curated seed variants, four character/voice bibles, and scene cards.
2. Build typed state, explicit effects, isolated knowledge, deterministic scheduling, narrative preference adaptation, and validated versioned saves.
3. Author branching scenes with safe alternatives; connect street, club, apartment and Motel 27.
4. Build a responsive editorial game shell, local phone, evidence journal, wardrobe, boundaries, sound, save management and development inspector.
5. Validate narrative graph; simulate contrasting routes and seeds; test knowledge, time, privacy controls, content exclusions and saves; browser-play and revise defects.

Decisions: React + TypeScript + Vite. Local-only; no account, analytics, live model, CDN or remote fonts. Art combines a local generated exterior, original SVG architecture and CSS lighting. Time advances on committed choices, never while reading. THE PULL models private narrative interest, attraction context, chemistry and thematic engagement. Adult characters, kink-aware classification and charged, non-graphic authored scenes create the night’s intimate atmosphere. NPC autonomy and player exclusions govern every encounter. Content filters substitute complete equivalent passages; exit choices remain accessible. Ordinary save mode has one bookmark plus autosave; Live Wire has one autosave and disables restore/import of bookmarks. Developer tools are build-time development only.

Scope truth: a first-night prototype, not the full city. Reading duration must be measured from authored content, not padded with timers. Record any shortfall against the requested 60–90 minutes in the final report.
